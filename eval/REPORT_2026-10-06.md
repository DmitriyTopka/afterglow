# Ranking eval, 06.10.2026

Setup (decided by Dima after an LLM council, before any measurement):
- Labels: a blind subagent saw only the catalog (id, title, category, price) and the messages. Tune s01-s03, holdout n01-n06, sealed x01-x03 (written by the same blind agent, never read before the final run). Commit 4b33c45.
- Arms: random (same budget + one-per-category rules), rules (direct matches from shop metadata + tag overlap, no Qloo), qloo (same direct matches + Qloo z-lift over 12 fixed reference profiles).
- Only the tune set was used for choices (lift mode: z, raw and diff tried). Holdout and sealed were run once, after freezing (commit 950ed9c).
- Pooled judging: every pick from either arm that the labels did not cover was judged yes/no by a second blind subagent without knowing the arm (eval/pool_verdicts.json, 8 yes / 38 no).
- Extractor: rule-based mock (LLM_MODE=mock), all scenario names come from its fixed list.

## Reading
- The jump from 0.11 to ~0.7-0.8 comes from direct matches (shop metadata: creators/works) and from fixing signal resolution (Studio Ghibli resolved to "Picsart Photo Studio"). Both are not Qloo.
- On held-out queries the Qloo arm does not beat the no-Qloo rules arm: 0 wins, 4 losses, 5 ties on P@3; cross-domain 0.44 vs 0.48. With 9 queries this is a direction, not a precise number.
- The rules arm leans on hand-written mock_tags; a real store may not have them, so the baseline is optimistic.
- Old criterion (P@3 >= 0.67 on 3 old + 6 new) is met by the qloo arm (1.00 and 0.72), but the council criterion (qloo beats rules) is not. Per the stop rule, no further weight tuning.
- Qloo calls used today: ~140 of the 600 budget.
