# Eval v4: the agent after the council fixes (07.10.2026)

Same 40 frozen blind scenarios (eval/v2_scenarios.json). Only the agent was re-run (eval/v4_runs.json); the
Claude-only arm (the same model reading the whole 384-title catalog as text, no Qloo) is the v3 run, unchanged.
What changed in the agent since v3: no fixed plan in the prompt (goal and tool descriptions only), reasons may only
use the title's own data, more facts per candidate (Qloo tags, creators, year), repeated lookups merged, a solo
artist and their band count as one act in the store check.
Pooled = labels plus blind judge verdicts. The 11 new agent picks no judge had seen were judged blind this round
(4 yes, 7 no, eval/pool_v4_verdicts.json); earlier verdicts come from v2/v3 judges.

| set | metric | agent v4 | agent v3 | claude-only | v4 vs claude W/L |
|---|---|---|---|---|---|
| all 40 | labels P@3 | 0.44 | 0.40 | 0.29 | 21/5 |
| all 40 | pooled P@3 | 0.62 | 0.56 | 0.43 | 22/7 |
| even 20 (clean) | labels P@3 | 0.48 | 0.38 | 0.37 | 10/3 |
| even 20 (clean) | pooled P@3 | 0.63 | 0.50 | 0.55 | 9/4 |

Routes the model chose: find_tastes > score_catalog > check_store > recommend in 37 of 40; once it skipped the store
check, twice it asked the shopper a question (v19, v25) although it had tastes, once (v07) its recommend ids did not
match the candidates and it returned nothing. Those three count as zero here. Fixed after this run (a question is
refused once tastes and candidates exist; a short answer is topped up from the scored candidates); not re-measured.
Cost: $0.53 for 40 requests (3.9 model turns on average), 53 live Qloo calls.

Reading
- On the 20 scenarios never used for tuning the agent now beats Claude alone on both measures (labels 0.48 vs 0.37,
  10 wins, 3 losses). In v3 this half was a tie.
- Caveat: the new picks were judged by a new blind judge; judge drift between rounds is possible.
- Without a fixed plan the model still takes the same route almost every time: the natural order of the task.
  The agent's freedom shows in what it looks up (genres become representative works, e.g. "westerns" became
  The Lone Ranger and Bonanza) and when it stops, not in the order of tools.
