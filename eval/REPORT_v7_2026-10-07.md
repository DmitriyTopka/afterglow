# Eval v7 (07.10.2026): asked formats filled from the shopper's own taste in that format

## Change since v6
When the shopper asks for a format ("cozy fantasy books like The House in the Cerulean Sea"), the agent now fills it with the titles
that the named taste of that format pulls hardest (Qloo explainability), not the titles of that format that rank high on the whole
request. On the recorded example this replaced "American Kingpin" (true crime) with "Under the Whispering Door" (same author as the
named book), "Chain of Thorns" and "Chain of Gold".

## The 40 frozen blind scenarios
`npx tsx scripts/eval_v5.mts eval/v7_runs.json`, `python3 scripts/score_v5.py eval/v7_runs.json`. 7 new top-3 picks went to a blind
judge: 0 yes, 7 no (`eval/pool_v7_verdicts.json`).

Over-budget titles in the top three across 40 requests: v7 0, v6 0, Claude alone 12.

## Run-to-run variance
Top-3 picks changed on 29 of 40 requests between v6 and v7. Only 6 of those name a format, the one code path that changed; there the
labels went from 7 to 8 hits. The other 23 changed because the model chose differently on the same code. So a single run of this agent
moves by a hit or two on the frozen set, and the gap to Claude alone (0.48 vs 0.37 on labels) is larger than that movement but small in
absolute terms. We publish the latest run, not the best one.
