# Eval v8 (07.10.2026): review fixes, measured on the same 50 untuned requests

## What changed since v7 (`lib/agent/agentic.ts`, `lib/agent/tasteTags.ts`)
- An empty candidate pool no longer traps the agent: recommend is refused only before scoring, a strict format with nothing in budget
  falls back to the mixed pool with a note, and the last resort is popular titles within the budget. Before, "90s hip hop on vinyl
  under $15" spent six turns and returned nothing.
- Format words without false positives: "series" alone is no longer TV (a book series), "switch" alone no longer a game,
  "watch" no longer forces a film.
- The recipient's age only from words about the recipient: not "my kid brother, he's 25", not "a Teen Titans fan".
- Taste tags no longer vanish when the only named taste is a brand (Studio Ghibli).
