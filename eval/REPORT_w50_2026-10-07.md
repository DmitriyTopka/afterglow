# Eval w50 (07.10.2026): 50 requests never used for tuning, with intervals

The council asked for a bigger untuned test and an interval instead of a single number.

## Set
- 20 even-numbered scenarios of `eval/v2_scenarios.json` (written and labelled blind before any tuning; tuning used only the odd ones).
- 30 new scenarios, `eval/v3_scenarios.json`, written and labelled by a fresh blind agent on 07.10 after all tuning was done
  (10 with tastes the shop carries, 10 without, 10 mixed; 12 with a budget, 6 with the recipient's age). It saw only the catalog
  and the 40 earlier requests (to avoid repeats), never the agent.

## Arms
- Agent: the deployed agent (v7), `eval/v7_runs.json` and `eval/w30_runs.json`.
- Claude alone: the same model (claude-haiku-4-5) with the whole catalog as text and no Qloo, same prompt as eval v3
  (`scripts/eval_agent.mts`), `eval/v3_runs.json` and `eval/w30_runs.json`.

## Results (`python3 scripts/score_50.py`)
114 top-three picks that no label covered were judged blind, both arms shuffled together: 19 yes, 95 no (`eval/pool_w50_verdicts.json`).

| | agent | Claude alone | difference (95% paired bootstrap) | wins / losses | sign test |
|---|---|---|---|---|---|
| P@3, blind labels | 0.43 | 0.32 | +0.11 (-0.01 to +0.23) | 24 / 10 | p = 0.024 |
| P@3, labels + blind judge | 0.52 | 0.48 | +0.04 (-0.08 to +0.16) | 19 / 15 | p = 0.61 |

Over-budget titles in the top three: agent 0 of 70 requests, Claude alone 15 (12 on the first 40, 3 on the new 30).

## Reading
On the labels written before we saw any answer, the agent leads and the lead holds on the bigger set. With the second judge's
verdicts the two arms are close; the interval includes zero. The budget result is the cleanest difference. We publish the
latest run of the deployed agent.
